# 民谣食肆 · 点歌菜单

平板点歌菜单应用,支持后台管理歌单。

## 功能特性

### 前台功能
- 📱 响应式设计,支持平板和手机
- 🎵 按歌手分组显示歌曲
- 🔍 搜索歌曲名和歌手
- 📝 点歌本管理(添加/删除)
- 💾 数据自动保存到浏览器

### 后台管理功能
- 🔐 **密码保护** - 登录验证防止未授权访问
- ✏️ 添加/编辑/删除歌曲
- 📊 歌曲统计数据
- 📥 导入 JSON 格式歌单
- 📤 导出歌单备份
- 🔄 重置为默认歌单
- 🎯 快速搜索歌曲
- 🔑 修改管理密码

## 使用方法

### 前台点歌
1. 打开 `index.html`
2. 浏览歌曲列表或使用搜索功能
3. 点击歌曲卡片上的"点歌"按钮
4. 在右侧点歌本查看已点歌曲
5. 点击"移除"可取消点歌

### 后台管理
1. 点击前台页面右上角的"管理后台"按钮
2. 或直接访问 `admin.html`
3. **首次登录使用默认密码: `admin123`**
4. 登录后可以:
   - 添加新歌曲
   - 编辑现有歌曲信息
   - 删除歌曲
   - 导入/导出歌单
   - 重置为默认歌单
   - 修改管理密码(强烈建议首次登录后修改)
5. 会话24小时后自动过期,需重新登录
6. 点击"退出登录"可手动退出

## 部署到 Cloudflare

### 🎯 推荐方案: Cloudflare Pages(纯静态部署)

这是**最简单**的方式,直接部署静态文件。

#### 方法一: 通过 Git 自动部署

1. 将代码推送到 GitHub
2. 在 Cloudflare Dashboard 中:
   - 进入 **Pages** → 创建项目
   - 连接 Git 仓库
   - **构建配置留空**(无需构建命令)
   - 输出目录: `/`
   - 点击部署
3. 每次推送代码会自动重新部署

#### 方法二: 直接上传

```bash
# 安装 Wrangler CLI
npm install -g wrangler

# 登录
wrangler login

# 部署
wrangler pages deploy . --project-name=gedan
```

## 数据存储

- 使用浏览器 **localStorage** 存储数据
- 数据保存在本地浏览器中
- 不同浏览器/设备间数据不共享
- 清除浏览器数据会丢失歌单(建议定期导出备份)

## 常见问题

**Q: 默认管理密码是什么?**
A: 默认密码是 `admin123`,强烈建议首次登录后立即修改。

**Q: 如何修改管理密码?**
A: 登录后点击左侧"修改密码"按钮,输入当前密码和新密码即可修改。

**Q: 忘记密码怎么办?**
A: 清除浏览器 localStorage 数据(开发者工具 → Application → Local Storage),然后重新访问,会重置为默认密码 `admin123`。

**Q: 会话多久过期?**
A: 登录会话24小时后自动过期,需重新输入密码登录。

**Q: 如何备份歌单?**
A: 在管理后台点击"导出歌单"按钮,会下载 JSON 文件。

**Q: 如何恢复歌单?**
A: 在管理后台点击"导入歌单",选择之前导出的 JSON 文件。

**Q: 数据存在哪里?**
A: 数据存在浏览器的 localStorage 中,更换浏览器或清除数据会丢失。

**Q: 多台设备能共享数据吗?**
A: 不能,每台设备独立存储。如需共享,请使用"导出/导入"功能。

---

**💡 提示**: 建议定期导出歌单备份,避免数据丢失。
